# Repository Protection

Repository protection uses two complementary flows:

- [Repository Monitoring](repository-monitoring.md) evaluates files as changes are detected.
- [Full Repository Scan](repository-full-scan.md) enumerates and evaluates existing content in a selected scope.

Both use the durable scan, policy, remediation, and result pipeline described in [DSX-Connect 2 Architecture](architecture.md). For application-initiated uploads and transfers, see [Governed File Movement](governed-file-movement.md).
